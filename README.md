Uses LangGraph + Gemini to handle research, structuring, and slide generation, with FastAPI backend for deployment.

---

### 🤖 Automated AI Opportunity Agent
Autonomous pipeline that scans Gmail, extracts structured opportunity data, and logs it into Google Sheets.  
Implements LLM-based parsing + filtering + Telegram alerts with scheduled execution via GitHub Actions.

---

### 🏥 Clinical QA Bot (Mistral-7B Fine-tuned)
Fine-tuned Mistral-7B using QLoRA for medical MCQ answering.  
Focused on domain adaptation and evaluation on hard unseen questions.

---

### 🎯 Hangman Solver — Hybrid Ensemble
Built a dynamic ensemble of Transformer + CANINE models.  
Combines probabilistic heuristics (early game) with learned policies (mid/late game) for optimized guessing.

---

### ⚛️ Hybrid Quantum ML (HQNNs)
Explores quantum-classical hybrid models for imbalanced classification.  
Includes fraud detection and melanoma classification with measurable gains over classical baselines.

---

### 📱 Finlytics (AI Finance App)

Focus on intelligent insights, categorization, and user-friendly financial tracking.
